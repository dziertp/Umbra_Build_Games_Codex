# Accesorio de personaje: gorro rojo de orejas largas

**Diseño:** Anais Tapia, con asistencia de Codex.  
**Estado:** propuesta visual para revisión; accesorio separado del sprite base.

## Archivo

- `assets/characters/accessories/gorro_rojo_orejas_4_vistas_24x22.png`: hoja transparente con cuatro celdas de 24 × 22 píxeles, ordenadas frente, espalda, perfil izquierdo y perfil derecho.

El gorro toma como referencia general un gorro rojo de orejas largas y medallón amarillo. El diseño está dibujado en bloques de píxel para acercarse al estilo de los avatares del proyecto. El montaje de ejemplo sobre Hannah es solo una vista previa: el archivo original `docs/personajes/Hannah_Model.png` no se modificó. El accesorio todavía no se integró al juego ni se asignó a todos los personajes.
